🎨 一、色彩系统

MiMo 采用极简、克制的配色策略：以 暖灰白 (#FAF7F5) 为基调，搭配纯黑文字与黑色分隔线， 构建出干净、理性、具有人文气息的视觉氛围。点缀色（如青绿 #5ED4AD）极少出现，仅用于特定功能区域。 整体遵循「少即是多」的小米设计哲学。

🎯 色彩应用核心规则

1. 大面积永远是 #FAF7F5：主背景必须使用暖灰白色，纯白只在特定容器内出现
2. 分隔线必须用纯黑 1px：区块与区块之间、产品卡片之间，用黑色实线分隔是 MiMo 的标志性语言
3. 强调色要「吝啬」使用：青绿色和蓝色渐变只在需要突出的地方出现，不超过页面元素的 5%
4. 文字对比度必须足够：正文 ≥ #333333，只有辅助文字可到 #666666 或更低

2.2 布局节奏 (Rhythm)

MiMo 的页面节奏由「大标题 (h2 40px) → 内容卡片」的重复模式构成，每一个主要区块（Section）都遵循以下内部结构：

第二条卡片 (同样式重复)
描述文字保持一致风格

2.3 响应式断点

基于实际页面表现推断的断点设置：

📱 移动端关键特征

1. 导航栏显示 Hamburger 图标（36×56px 尺寸）

3. 单列纵向流式布局，不出现多列并排
4. 卡片内容左右 Padding 从 28px 缩至 24px

🔤 字体应用核心规则

1. 行高规律：大标题行高约 170%，小标题行高约 130%，正文行高约 150-170%
2. 字重策略：Hero 必用 700，区块标题 700，卡片标题 600，导航 500，正文一律 400
3. 字间距：H1 和 24px 产品标题使用额外字间距（1.12px / 0.24px），增加呼吸感
4. 颜色区分层级：黑色 = 标题，#213547 = 正文，#666666 = 副信息，rgba(0,0,0,0.4) = 极弱信息

✨ 四、图标系统

MiMo 网站的图标使用非常克制，主要以 SVG 图标呈现。整体风格为极简几何、面性填充或 单线条，配合 16px 和 32px 两种标准尺寸。

🎬 五、交互动效系统

5.3 滚动触发动效

  • 导航栏：position: sticky，top: 0，z-index: 20，滚动时持续吸顶
  • Hero 图案：6 行文字水平滚动（偶数行反向），营造视差背景
  • 区块进入视口：卡片内容透明度 0 → 1，轻微向上位移（推测 16-24px）
  • 产品卡 Hover：整体无位移，仅文字颜色和透明度微变

✅ 九、设计一致性检查清单

在个人网站实现完成后，逐项对照以下清单，确保视觉风格和交互体验与 MiMo 官网保持高度一致。

9.1 色彩一致性

  • 页面主背景色为 #FAF7F5（非纯白 #FFFFFF）
  • 区块/产品卡片之间使用 1px 纯黑实线分隔
  • 标题文字均为 #000000，未使用深蓝或其他颜色
  • 副标题使用 #666666 或 rgba(0,0,0,0.4)，深浅符合层级
  • 强调色 #5ED4AD / 蓝色渐变占比不超过 5%
  • 导航栏使用白底/透明，与 Hero 有明显区分

9.2 字体一致性

  • Hero 主标题字号 56px（桌面端），字重 700，行高 95.2px，字间距 1.12px
  • 区块大标题统一 40px / 700 / line-height 68px
  • 产品卡片标题 24px / 600，Paper/Blog 列表标题 20px / 600
  • 产品卡片副标题 13px rgba(0,0,0,0.4)，列表卡片副标题 14px #666666
  • 所有文字已设置 MiSans 回退字体链，兼容各种系统
  • 大、小标题颜色为纯黑 #000000，未出现蓝色链接色

9.3 布局/间距一致性

  • 导航栏高度 56px，sticky 吸顶，z-index ≥ 20
  • Hero 区高度 600px，上下有 1px 纯黑边框，标题底对齐
  • Hero 背景包含 6 行 MIMO 滚动图案（奇偶数行反向）
  • 产品卡上下 padding 24px、左右 28px；列表卡左右 20px
  • 列表卡片标题下方 margin 为 8px，与副标题间距正确
  • 卡片之间无线性灰色分割线，而是继承父背景，保持干净
  • 所有间距均使用 4px 的倍数，未出现 3/5/7 等奇数像素

9.4 交互/动效一致性

  • 导航按钮 hover 时透明度下降至约 0.7，0.2s 过渡
  • 下拉菜单项 hover 时背景变 #E5E7EB，0.15s 过渡 + 8px 圆角
  • 卡片整体 hover 无位移/缩放，仅颜色/透明度微变 0.4s
  • 导航栏无阴影 (box-shadow: none)，极简不抢视觉
  • 卡片无圆角 (border-radius: 0) 或极小圆角，避免「圆润」
  • 产品图片 hover 时如有放大，使用 cubic-bezier(0.2,0,0.2,1) 曲线
  • 页面滚动时导航栏保持吸顶不抖动

9.5 响应式一致性

  • ≤ 480px 宽度时 Hamburger 菜单可见，桌面导航隐藏
  • 移动端 Hero 标题缩小至约 40px，不产生横向滚动条
  • 移动端卡片 Padding 调整至 24px，不溢出视口
  • 在 375px (iPhone SE) 下测试无错位问题
  • ≥ 1024px 时恢复完整桌面导航和大字号

⚙️ 十、技术建议与注意事项

🎯 实现顺序建议

第一步：CSS 变量定义 → 第二步：基础样式 reset + 全局字体背景 → 第三步：Navbar 组件 → 第四步：Hero 区域（含背景动画） → 第五步：产品卡片组 → 第六步：列表卡片（Paper/Blog） → 第七步：Join Us → 第八步：响应式适配

10.1 技术栈建议

层级推荐方案原因
结构HTML5 + Semantic 标签section/header/nav/article 语义化，利于 SEO
样式CSS3 + CSS Variables零依赖，便于使用本规范的变量集
字体MiSans CDN + 系统回退小米官方字体可用 CDN；回退链确保兼容
动画CSS Keyframes + TransitionsHero 背景滚动和状态变化均可用纯 CSS 实现
可选增强IntersectionObserver实现滚动触发的卡片淡入动效

10.2 常见陷阱与规避

  • 陷阱：背景用了 #FFFFFF 而不是 #FAF7F5，感觉「太冷太硬」
  • 陷阱：Hero 标题居中对齐而不是底部对齐，失去了独特的节奏感
  • 陷阱：卡片加了 8px+ 的圆角或阴影，变成「电商风」而不是「极简科技风」
  • 陷阱：过度使用过渡效果（3D transform / 弹跳），破坏克制的基调
  • 陷阱：产品卡之间使用浅灰分隔线，弱化了高级感。必须用 1px 纯黑实线！
  • 陷阱：Hero 背景图案只做了一行或透明度过高/过低，没有层次感
  • 陷阱：「Join Us」链接使用了蓝色链接色，应该继承黑色文字

10.3 MiSans 字体加载方案

<!-- 方案 A：使用 CDN 加载 MiSans (推荐) -->
<link rel="stylesheet"
  href="https://font.sec.miui.com/font/css?family=MiSans:400,500,600,700&display=swap">

/* 方案 B：使用 @font-face 本地托管 */
@font-face {
  font-family: 'MiSans';
  font-weight: 400;
  src: url('/fonts/MiSans-Regular.woff2') format('woff2');
  font-display: swap;
}
@font-face {
  font-family: 'MiSans';
  font-weight: 600;
  src: url('/fonts/MiSans-Semibold.woff2') format('woff2');
  font-display: swap;
}

10.4 性能优化建议

  • 字体使用 font-display: swap，避免 FOIT（隐形文字）
  • Hero 背景动画使用 transform + GPU 加速，避免重绘
  • CSS 文件大小控制在 30KB 以内
  • Hero 图片使用 webp / avif 格式，响应式 srcset
  • scroll 事件监听器使用 passive: true
  • IntersectionObserver 用于触发懒加载和进场动画
